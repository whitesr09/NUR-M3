# NUR Material 3 — Build plan

This is a fresh native Android project. Original NUR repositories remain untouched.

## Milestone 1: Offline foundation
- Kotlin, Jetpack Compose and Material 3 with an independent application ID.
- Persistent prayer, Amanah and Muhasaba tracking. Entries survive midnight; daily completion is stored by local date.
- Daily Light progress, dashboard, history and appearance settings.
- A reproducible Gradle build and GitHub Actions APK artifact.

## Later milestones
- Prayer calculation and notification configuration, with an explicitly selected location and calculation method.
- Verified Quran and Hadith collections, reading/bookmark features, adhkar and tasbih.
- Advanced reminders, widgets, backup/import, accessibility and localization.
- Optional NUR AI using Gemini, with user-supplied credentials and clear source attribution.

No live religious data, prayer timetable, or AI response is claimed to exist before its implementation and verification. No private signing keys or API keys will be committed.
