NUR AI is optional. A user must enable network access and supply a personal Gemini API key. Store the key in the existing Android Keystore-backed private store, not DataStore, source, logs, URL query parameters, widgets or backups. Use the official HTTPS generateContent endpoint and a selected supported model. Do not enable grounding silently or invent Quran/Hadith references. AI output is advisory, not an authenticated fatwa. Clearly distinguish unverified responses, offer source links only when actually returned or independently verified, and allow independent deletion of chat history and credentials. Network failure must never modify prayer, task, or focus completion data.
