# NUR-M3 — levels 0.21–0.25

Source-only development continues from commit 0c8597173ba07ecb96e40cd3f11a8f2f0a18e82d. No APK build or release is requested. The repository currently contains the 0.14 application plus a 0.15–0.20 design boundary; do not treat that design document as proof that those modules are complete.

## 0.21 Focus & Routine Studio
Persist real focus sessions and routine definitions locally. Count only sessions that actually complete while the foreground timer is running. Pause, resume, cancel, and recover from process death without inventing elapsed work. Routine suggestions never create completion records.

## 0.22 NUR AI
Optional, user-consented Gemini chat with user-owned credentials. Keep credentials out of source, logs, backups, and widget data. No request is sent until the user explicitly enables networking and submits a message. AI text is not a verified religious source; provide citations only for sources actually consulted and distinguish uncertainty from rulings. History and credentials are independently removable.

## 0.23 Widgets & Quick Actions
Use existing recorded data, date-scoped counts and separate pending intents for each shortcut. Widget data is not a second source of truth. Refresh on database changes, day changes, and widget lifecycle events; avoid background loops and unsafe exported receivers.

## 0.24 Privacy & Backup Pro
Offer encrypted, versioned export with authenticated encryption, independent salt and nonce, bounded input and KDF parameters, and a user-supplied passphrase. Validate and preview before importing. Preserve legacy backup compatibility, exclude credentials and private journal material, and never silently overwrite existing records.

## 0.25 Accessibility & Final Experience
Respect system accessibility settings and app-specific reduced motion, provide labeled controls and adequate touch targets, support English/Malayalam/Arabic where reviewed strings exist, and give honest capability/performance diagnostics. Do not advertise unreviewed full translations or an untested production release.

The implementation status for each item must be updated from actual code and test evidence, not a roadmap. Existing NUR V2 repositories, the main branch, package name, and signing identity remain unchanged.
